# runledger

Открытый тренировочный лог с одной задачей: увести парковый забег на 5 км с 21:24 ниже 20:00
к концу апреля 2027 — под ежедневным руководством ИИ-агента, со всеми решениями, тренировками
и планами в простом тексте.

Репозиторий публичный, но написан для одного читателя — автора. Всё человекочитаемое здесь
по-русски.

## Как это устроено

```
Часы Coros ──► COROS MCP ──► агент (Claude Code / Codex / GLM)
                                  │  читает AGENTS.md, работает по SOP
                                  ▼
                        data/*.yaml ── источник правды
                          │                │
              tools/runkit (Rust)     site/ (Next.js, статика)
              reports/DASHBOARD.md    дашборд на бесплатном Pages
```

- Я прихожу и говорю «я побегал». Агент забирает тренировку с часов Coros через MCP, раскладывает
  по файлам, обновляет план недели и отвечает короткой обратной связью.
- Всё человекочитаемое живет в YAML/Markdown в `data/`: тренировки, недельные планы, гонки,
  документ цели, профиль спортсмена с пульсовыми зонами.
- `tools/runkit` — небольшой CLI на Rust для детерминированной работы: импорт GPX/TCX, проверка
  данных и тренерских предохранителей, генерация отчетов.
- `site/` — статический дашборд из тех же YAML (без бэкенда, бесплатный хостинг GitHub/GitLab
  Pages).
- `AGENTS.md` — рабочая инструкция, по которой любой ИИ-агент (Codex, Claude Code, GLM…) работает
  тренером. `CLAUDE.md` просто импортирует её.

## Карта репозитория

| Путь | Что там |
|---|---|
| `AGENTS.md` | рабочая инструкция для агентов |
| `data/athlete/` | профиль: пульсовые зоны, пороги, шаблон недели, травмы, обувь |
| `data/workouts/` | один YAML на тренировку |
| `data/plan/` | планы по неделям (ISO-недели) |
| `data/goals/5k-sub20.md` | документ цели: фазы, вехи, история забегов |
| `data/races/` | календарь гонок и результаты |
| `reports/` | сгенерированные дашборд и недельные сводки |
| `tools/runkit/` | CLI на Rust: `ingest`, `report`, `validate`, `plan new` |
| `site/` | статический дашборд на Next.js |
| `docs/data-model.md` | контракт данных |

## Приватность

Репозиторий публичный, интимного в нём нет. Записи тренировок — только метрики: дистанция, время,
темп, пульс, структура. GPS-треки и сырые выгрузки с часов остаются локально (`raw/`, в git не
попадают), выгрузки здоровья (сон/HRV) — тоже (`data/health/`, gitignored).

## Инструменты

```bash
cd tools/runkit && cargo run --release -- report     # перегенерировать reports/
cd tools/runkit && cargo run --release -- validate   # проверка данных и предохранителей
cd site && pnpm build                                # статический дашборд -> site/out
```
