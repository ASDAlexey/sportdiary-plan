## Повторный импорт

Сохраните очищенный список Coros в локальный файл raw/coros-records.json.
Он содержит массив записей, например:

```json
[{"id":"123","date":"2026-10-03","sport_type":100,"distance_km":6.01,"moving_time_s":2284,"avg_hr":139}]
```

Из корня репозитория выполните:

```sh
cargo run --release --manifest-path tools/runkit/Cargo.toml -- --root . sync-coros raw/coros-records.json
cargo run --release --manifest-path tools/runkit/Cargo.toml -- --root . validate
cargo run --release --manifest-path tools/runkit/Cargo.toml -- --root . report
pnpm -C site build
```

Индекс raw/coros-index.json связывает Coros с файлами журнала. Сохраняйте его для следующих синхронизаций.
Команда сохраняет ручные заметки, обувь и структуру. Неоднозначное совпадение останавливает импорт.
Не запускайте report из tools/runkit без --root ../..: иначе отчёт попадёт в каталог инструмента.

GPS в публичном журнале отсутствует. raw/ остаётся локальным.
После расширения истории validate сообщает о прежних скачках объёма; это предупреждения по прошлым неделям.
