# Архитектурные решения

Почему репозиторий устроен именно так. Краткие обоснования, а не спека — спека это
`data-model.md`.

## Простой текст как источник правды

Тренировки, планы, гонки и профиль спортсмена — YAML/Markdown в `data/`. База данных — git:
история, диффы, слияния и разрешение конфликтов бесплатно; любой агент или человек читает и правит
без настройки окружения. Отчеты и сайт — производные артефакты, перегенерируемые по требованию.

## AGENTS.md — конституция

Этим репозиторием пользуются разные агенты (Claude Code, Codex, GLM) из разных харнессов.
`AGENTS.md` — единственная рабочая инструкция: SOP, факты о спортсмене, жесткие правила.
`CLAUDE.md` импортирует его (`@AGENTS.md`), Codex читает нативно. Ничего агентоспецифичного
больше нигде нет, поэтому смена инструмента не теряет контекст, и ни один агент не переспрашивает
то, что уже написано.

## Coros через MCP, а не через scraped API

Данные с часов приходят через официальный MCP-сервер COROS (`.mcp.json`): агент забирает тренировки
напрямую, без ручных выгрузок, без реверс-инжиниринга облачного API, учетные данные живут в
приложении Coros. Файловые дропы (`raw/` GPX/TCX/FIT) остаются запасным путём для харнессов без
поддержки MCP.

## Детерминированное — в Rust, суждения — в агенте

Всё точное — подсчет итогов из GPX, запись файлов отчетов, проверка схем и тренерских
предохранителей — делает `tools/runkit` (Rust). Свободные суждения (тренерская обратная связь,
план недели, перестройка после плохой ночи) — за агентом. Отчеты руками не правятся: месяц
ежедневных записей не расползается в несогласованные форматы.

## Статический сайт на бесплатном хостинге

Дашборд — статически экспортируемое Next.js-приложение, читающее `data/` на этапе сборки. Без
бэкенда, без базы, без затрат: GitHub Pages и GitLab Pages раздают бесплатно, что и нужно публичным
зеркалам. `NEXT_PUBLIC_BASE_PATH` подстраивает сайт под любое будущее имя репозитория.

## Приватность через отсечение, а не через сокрытие

Репозиторий публичный, поэтому личное отсекается на границе: сырые файлы с GPS-треками не входят
в git (`raw/` игнорируется), в YAML тренировок — только метрики, данные здоровья остаются локально
(`data/health/`, игнорируется). Публикуется ровно то, что уместно в открытом тренировочном логе.

## Минимализм как принцип

Один крейт Rust, одно Next.js-приложение с горсткой зависимостей, без Tailwind, без базы, без
планировщиков. Настоящий двигатель системы — человек, говорящий «я побегал», и агент с хорошей
инструкцией. Каждая движущаяся часть обязана оправдать себя.
